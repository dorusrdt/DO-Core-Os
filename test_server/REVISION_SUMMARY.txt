MODÈLE: IrrigationSchedule
────────────────────────────────────────────────────────────────────────────
class IrrigationSchedule(BaseModel):
    time: str                              # Format HH:MM
    duration: int                          # 1-300 minutes
    daysOfWeek: List[int]                  # 0=Dim, 1=Lun, ..., 6=Sam
    isActive: Optional[bool] = True

Validation Pydantic:
  ✅ time: Non-vide, format HH:MM
  ✅ duration: Entier (1-300)
  ✅ daysOfWeek: Liste d'entiers (0-6)
  ✅ isActive: Boolean ou None (default True)


MODÈLE: ZoneConfig (MIS À JOUR)
────────────────────────────────────────────────────────────────────────────
class ZoneConfig(BaseModel):
    zoneId: str                                          # ID de la zone
    physicalZoneNumber: int                 ← NOUVEAU   # Numéro relais
    waterPerDay: int                                     # ml/jour
    irrigationTime: Optional[str] = None    ← Legacy    # Rétrocompat
    irrigationTimes: Optional[List] = None  ← Legacy    # Rétrocompat
    irrigationSchedule: Optional[...] = None ← NOUVEAU   # Horaires détail
    humidityThreshold: int                               # %
    sensors: List[SensorConfig]                          # Capteurs

Validation Pydantic:
  ✅ zoneId: String non-vide
  ✅ physicalZoneNumber: Integer (OBLIGATOIRE)
  ✅ waterPerDay: Integer > 0
  ✅ humidityThreshold: Integer 0-100
  ✅ sensors: Liste non-vide de SensorConfig
