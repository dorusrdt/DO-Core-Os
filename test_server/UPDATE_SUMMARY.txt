🔌 NOUVEAUX ENDPOINTS
──────────────────────────────────────────────────────────────────────────────

Zone Management:
  POST   /api/devices/{id}/zones           Ajouter zone
  GET    /api/devices/{id}/zones           Lister zones
  GET    /api/devices/{id}/zones/{zid}     Obtenir zone
  DELETE /api/devices/{id}/zones/{zid}     Supprimer zone

Web Management:
  GET    /api/devices/{id}                 Info device
  GET    /api/devices/{id}/status          Status + dernière data
  DELETE /api/devices/{id}                 Unregister device

Sensor Data Enhanced:
  GET    /api/sensor-data/history          Historique
  GET    /api/sensor-data/latest/{id}      Dernière data

🚀 UTILISATION
──────────────────────────────────────────────────────────────────────────────

Démarrer le serveur:
  $ python3 irrigation_server.py
  $ # Ou: ./run_server.sh

Créer zones de test:
  $ ./create_test_zones.sh

Lancer les tests:
  $ ./test_server.sh

Accéder à la documentation:
  • Swagger: http://localhost:8000/docs
  • ReDoc: http://localhost:8000/redoc
