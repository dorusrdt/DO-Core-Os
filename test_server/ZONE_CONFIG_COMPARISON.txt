📌 PROBLÈME IDENTIFIÉ
═════════════════════════════════════════════════════════════════════════════
Le modèle ZoneConfig manquait DEUX champs critiques :
  1. ❌ physicalZoneNumber - Numéro physique du relais (1-4)
  2. ❌ irrigationSchedule - Tableau d'horaires détaillés

L'ESP32 attendait ces champs pour :
  • Mapper les zones aux relais physiques corrects
  • Gérer les horaires d'irrigation avec jours de la semaine
  • Parser la configuration complète du serveur

❌ Problèmes:
  • Pas de numéro de relais -> ESP32 ne sait pas quel relais activer!
  • Un seul horaire -> Pas de diversification des arrosages
  • Pas de jours de la semaine -> Tous les jours même heure

✅ Améliorations:
  • physicalZoneNumber: 1 -> Relais #1 activé correctement!
  • 2 horaires d'arrosage -> Flexibilité maximale
  • Jours spécifiques -> Lun/Mer/Ven: 08:00 | Dim/Mar/Jeu/Sam: 18:00
  • Duration variable -> Chaque horaire peut avoir sa durée


🔀 JOURS DE LA SEMAINE (daysOfWeek)
═════════════════════════════════════════════════════════════════════════════

Index   Jour         Description
────────────────────────────────────────────────────────────────────────────
  0     Dimanche     [0]
  1     Lundi        [1]
  2     Mardi        [2]
  3     Mercredi     [3]
  4     Jeudi        [4]
  5     Vendredi     [5]
  6     Samedi       [6]

Exemples de jours:
  [1, 3, 5]        = Lundi, Mercredi, Vendredi
  [0, 2, 4, 6]     = Dimanche, Mardi, Jeudi, Samedi
  [1, 2, 3, 4, 5]  = Lundi à Vendredi (semaine)
  [0, 6]           = Samedi, Dimanche (week-end)
  [0, 1, 2, 3, 4, 5, 6] = Tous les jours
